# Arbetarjul

Är det en arbetarjul, gråsossejul eller arbetsgivarjul i år? Statisk sida som räknar ut det svenska ledighetsutfallet (röda dagar på vardagar, klämdagar) för valfritt år.

- `index.html` – sidan
- `calc.js` – beräkningsmotor (helgdagar, klämdagar, klassificering); körbar i Node för test
- Publiceras via GitHub Pages på https://arbetarjul.cptjanst.se

En tjänst från CP-tjänst.
